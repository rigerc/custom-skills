# Reference release checklist

- [ ] Release owner and on-call contacts confirmed.
- [ ] Scope, version/tag, release notes and change window agreed.
- [ ] CI checks and relevant functional tests pass.
- [ ] Backups, migration strategy and rollback plan reviewed.
- [ ] Deployment permissions and secrets verified without exposing their values.
- [ ] Monitoring, error budget and success metrics defined.
- [ ] Rollout begins only after human approval.
- [ ] Smoke tests and key user journeys pass.
- [ ] Stakeholders notified; any regressions triaged.
- [ ] Release status recorded with links to logs and follow-up issues.
